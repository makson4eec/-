Практическая работа №1 по Java

Задание 1: все 49 вариантов из архива исправлены, по отдельному исходнику на вариант.
Задание 2: все 10 формул из документа, каждый вариант в своём каталоге. Для номера варианта больше 10 используйте последнюю цифру (10, 20, 30 и т.п. -> вариант 10).
Задание 3: все 10 вариантов задач с if.
Задание 4: расчёт покупки со скидкой и проверкой данных.

Как запускать (из соответствующего каталога):
  javac Variant1.java
  java Variant1
Для четвёртого задания: javac Main.java && java Main
Второе задание: x вводится через точку.
